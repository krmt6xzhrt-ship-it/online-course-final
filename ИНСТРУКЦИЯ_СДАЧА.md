# Как сдать Online Course App — инструкция с нуля

## 1. Распаковка
1. Скачай ZIP и распакуй его.
2. Открой **Terminal** на Mac или терминал VS Code.
3. Перейди в распакованную папку. Проще всего: набери `cd ` (с пробелом) и перетащи папку `online-course-final` в окно Terminal, затем Enter.

## 2. Запуск — копируй команды по одной
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py makemigrations onlinecourse
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser
python manage.py runserver
```
`createsuperuser`: придумай имя и пароль, сохрани их. Пароль может не отображаться при вводе — это нормально.

## 3. Сделай реальный скриншот 03-admin-site
1. Открой http://127.0.0.1:8000/admin/
2. Войди под суперпользователем.
3. В кадре должны быть **Authentication and Authorization** и **Onlinecourse**.
4. На Mac нажми `Command + Shift + 4` и выдели окно админки.
5. Переименуй файл в `03-admin-site.png`.

## 4. Сделай реальный скриншот 07-final
1. Открой http://127.0.0.1:8000/
2. Перейди в курс **Python & Django Fundamentals**.
3. Если требуется, выполни вход под своим суперпользователем.
4. Ответь на 5 вопросов:
   - def
   - models.py
   - POST
   - `{{ variable }}`
   - A route to a view
5. Нажми **Submit exam**.
6. Убедись, что видно **Congratulations!**, **100%**, **Score: 100 / 100** и заголовок **Exam results**.
7. Сделай скриншот `Command + Shift + 4` и назови `07-final.png`.

## 5. Загрузка файлов проекта на GitHub (способ без Git-команд)
1. Войди на https://github.com/ и нажми **New repository**.
2. Название: `online-course-final`, видимость: **Public**, затем **Create repository**.
3. В новом репозитории выбери **uploading an existing file** (или Add file → Upload files).
4. Открой распакованную папку и загрузи файлы и папки проекта, сохранив пути `onlinecourse/...` и `myproject/...`. НЕ загружай `.venv`, `db.sqlite3`, личные пароли.
5. Нажми **Commit changes**.
6. Если веб-интерфейс GitHub не принимает папки, используй команды ниже.

### Альтернатива — Git через терминал
Создай пустой **Public** репозиторий `online-course-final` на GitHub, затем из папки проекта:
```bash
git init
git add .
git commit -m "Complete Django Online Course App assessment"
git branch -M main
git remote add origin https://github.com/USERNAME/online-course-final.git
git push -u origin main
```
Заменить USERNAME на свой GitHub username. Если система попросит вход, используй авторизацию GitHub через менеджер учётных данных / GitHub CLI.

## 7. Если что-то не работает
- `python: command not found` → используй `python3`.
- `No module named django` → активируй `.venv` и повтори `python -m pip install -r requirements.txt`.
- `Port already in use` → запусти `python manage.py runserver 8001` и открывай `http://127.0.0.1:8001/`.
- `no such table` → выполни `python manage.py migrate`.
- Не загружай вымышленные скриншоты: оба должны быть сняты с реально работающего приложения.
